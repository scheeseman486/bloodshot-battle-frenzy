# Authored small-font additions

`small_font_additions.png` contains the project's authored white pixels for 65
missing printable characters and two extra columns for the runtime CD hyphen.
It contains no recovered CD glyph pixels, reference layers or background.

The original glyphs are read from the developer's own supported European Mega CD
image at runtime. The adjacent `../ui/cd_small_font_inventory.json` records the
authored overlay's checksum and original-media identities. The PNG is an addition
to that runtime font, not a complete copy of the original atlas.
