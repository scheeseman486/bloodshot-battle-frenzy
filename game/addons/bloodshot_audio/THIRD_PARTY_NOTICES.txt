Third-party software in bloodshot_audio
=======================================

mightyweenie's existing MwChips, PSG and PCM mixer are reused under BSD-3-Clause.
Their copied source hashes and origin are recorded in native/audio/mightyweenie-provenance.json.
The CD game uses native PCM playback; only FM synthesis uses MwChips/ymfm.
Linux builds compile libchdr and its codecs plus full zstd into the extension
inside the pinned Ubuntu 20.04 environment. LINUX_NATIVE_NOTICES.txt carries the
additional codec notices. No host codec shared library is bundled.
Windows builds statically link libchdr, its codecs, full zstd and MinGW runtimes;
WINDOWS_NATIVE_NOTICES.txt includes their additional exact notices.
The static GNU runtimes use the GCC Runtime Library Exception.
Dependency versions/hashes are pinned in tools/build_audio.py and native-build.json.
